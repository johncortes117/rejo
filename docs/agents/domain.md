# Domain docs

REJO usa un único contexto de dominio.

Antes de explorar o modificar código, lee:

- CONTEXT.md en la raíz;
- las ADRs de docs/adr/ que afecten el área.

Usa el vocabulario definido en CONTEXT.md en issues, especificaciones, pruebas y nombres de conceptos. Si una solicitud contradice una ADR, señala el conflicto explícitamente en vez de sustituir la decisión de forma silenciosa.
