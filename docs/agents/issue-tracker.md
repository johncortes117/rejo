# Issue tracker: GitHub

Los issues y las especificaciones de REJO viven en GitHub Issues. Usa el CLI gh para crearlos, leerlos, comentarlos, etiquetarlos y cerrarlos.

## Convenciones

- Crear un issue con gh issue create, usando el remoto del repositorio.
- Leer un issue con gh issue view <número> --comments.
- Listar issues con gh issue list y los campos de etiquetas y comentarios que sean necesarios.
- Aplicar o quitar etiquetas con gh issue edit <número>.
- Cerrar un issue con gh issue close <número>.

## Pull requests como fuente de triage

PRs como fuente de solicitudes: no.

## Publicación solicitada por una skill

Cuando una skill pida publicar en el issue tracker, crea un GitHub Issue.
