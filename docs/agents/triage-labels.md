# Triage labels

Las skills usan cinco roles canónicos. Esta es su correspondencia con las etiquetas de GitHub de REJO.

| Rol de la skill | Etiqueta en GitHub | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | El mantenedor debe evaluar el issue |
| needs-info | needs-info | Falta información del reportante |
| ready-for-agent | ready-for-agent | Está especificado y listo para un agente |
| ready-for-human | ready-for-human | Requiere implementación humana |
| wontfix | wontfix | No se realizará |
